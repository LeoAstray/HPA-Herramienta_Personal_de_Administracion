# Documentación general publicada

Esta carpeta está separada de las áreas Markdown numeradas. Contiene artefactos de lectura y el contexto específico de cada publicación.

## Estructura

- `publicaciones/`: ediciones consolidadas en DOCX y PDF, organizadas por fecha y hora.
- `fuentes/`: DOCX/PDF históricos y originales, separados por especificación y ADR.
- `contexto/`: notas Markdown asociadas a una publicación o necesarias para interpretar un artefacto de lectura.

La fuente de verdad mantenible del proyecto sigue estando en los Markdown de las áreas numeradas de `docs/`. Los agentes deben leer esos documentos primero y usar esta carpeta para consultar una edición concreta.
