# Estudio global de módulos — Fase 1

## Objetivo

Definir el papel y los límites de cada módulo antes de diseñar la arquitectura global. Los documentos de esta carpeta no son una decisión técnica salvo que lo indiquen expresamente.

## Método común

Cada estudio debe responder: propósito, problema, capacidades, límites, entidades, relaciones, dependencias, seguridad, automatizaciones, interacción, MVP, futuro y decisiones pendientes.
