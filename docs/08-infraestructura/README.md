# Infraestructura

El objetivo inicial es ejecución y datos en el ordenador del usuario, sin mensualidades obligatorias. El MVP deberá permitir acceso desde dispositivos de su red local; el modelo de despliegue, puertos, TLS, descubrimiento de servicio y restricciones de red están pendientes de diseño. El acceso remoto fuera de la red local no forma parte del alcance actual.
