# Glosario inicial

| Término | Significado en este proyecto |
| --- | --- |
| Core | Reglas y capacidades transversales independientes de una interfaz concreta. Su definición concreta está pendiente. |
| Entidad | Concepto del dominio que el sistema identifica y relaciona. El modelo definitivo está pendiente. |
| Módulo | Área funcional cohesionada del producto; no implica por sí sola un servicio técnico separado. |
| Cliente | Interfaz autorizada que usa operaciones del sistema: web inicialmente; móvil, voz o agentes en el futuro. |
| Integración | Adaptador con un sistema externo, desacoplado del núcleo. |
| Automatización | Regla o proceso que ejecuta una acción ante un desencadenante y bajo permisos definidos. |
| Área/Categoría | Clasificación estructurada de información. No se basa únicamente en etiquetas libres. |
| MVP | Mínima versión útil, segura, recuperable y extensible para el uso cotidiano. |
