# Testing

La estrategia de pruebas se diseñará junto con requisitos y arquitectura. Se mantendrá trazabilidad entre requisito, diseño, prueba y resultado.

## Piloto de agentes de desarrollo

El [diseño EVAL-05](../10-ia/diseno-evaluacion-permisos-agentes.md) define casos positivos y negativos, evidencia por operación, repetición y recuperación de un laboratorio sintético. Se registran por separado cumplimiento de instrucciones y controles técnicos. Las sondas técnicas corresponden a una persona bajo el mismo perfil verificable; no amplían los permisos del agente. Revisión independiente, entorno y ejecución pendientes. Este piloto no sustituye la futura estrategia de pruebas del producto.
