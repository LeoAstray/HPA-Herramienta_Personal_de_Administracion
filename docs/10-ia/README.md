# IA y agentes

Los agentes no son todavía una función aprobada del MVP. Conforme a ADR-003, el descubrimiento y diseño de IA/Agentes es la prioridad inmediata para determinar si algún agente debe entrar en el alcance posterior. Esta carpeta prepara contexto, límites y contratos documentales para que los agentes puedan asistir sin asumir autoridad ni acoplarse al núcleo.

El descubrimiento debe producir, antes de cualquier implementación, casos de uso priorizados, un inventario de agentes candidatos, criterios para evaluar modelos, límites de datos y permisos, y una decisión explícita de qué agente —si alguno— se implementará primero.

Leer primero [contexto-agentes.md](contexto-agentes.md) y [contrato-de-agentes.md](contrato-de-agentes.md).
